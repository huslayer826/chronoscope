# Browser Extension Store Submission

## Chrome Web Store

- Create a developer account and pay the one-time registration fee.
- Confirm the extension manifest uses Manifest V3.
- Verify all permissions are limited to tab URL/title access needed for local tracking.
- Include screenshots for the extension popup and ChronoScope desktop dashboard.
- Add a privacy policy URL that points to the ChronoScope privacy policy.
- Package the `extension/` directory as a ZIP without development artifacts.
- Submit for review and document the published store URL.

## Microsoft Edge Add-ons

- Create a Microsoft Partner Center account.
- Confirm Manifest V3 compatibility in Edge.
- Use the same minimal permissions and privacy policy as the Chrome listing.
- Provide store images, screenshots, category, and support contact.
- Upload the packaged extension ZIP.
- Submit for certification and document the published Add-ons URL.

## Firefox AMO

- Create a Firefox Add-ons developer account.
- Confirm the extension manifest and APIs are compatible with Firefox.
- Review any `browser.*` versus `chrome.*` API differences.
- Provide screenshots, description, support contact, and privacy policy.
- Upload the packaged extension ZIP.
- Submit for review and document the published AMO URL.
